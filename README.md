## 🪜 STEP-BY-STEP: The RIGHT Way to Create a Colab Notebook

### 1️⃣ Create Notebook in **Google Colab**

* Open Colab
* **File → New notebook**
* Rename immediately:

  ```
  01_Linear_Regression.ipynb
  ```

📌 Never leave default name like `Untitled0.ipynb`

---

### 2️⃣ Follow a STANDARD NOTEBOOK TEMPLATE (Mandatory)

Use this structure in **every notebook**:

```markdown
# 📘 Linear Regression – AI Ki Pathshala

## 🎯 What You Will Learn
- Concept
- Intuition
- Formula

## 🧠 Real-Life Example
House price vs area

## 🧮 Mathematics
Explain equation

## 💻 Code Implementation
Python + NumPy

## 📊 Visualization
Plots

## ❓ Practice
Modify learning rate
```

Consistency = student trust.

---

### 3️⃣ Use Markdown More Than Code (Teaching Rule)

| Type     | %   |
| -------- | --- |
| Markdown | 60% |
| Code     | 40% |

📌 Students learn **why**, not just **how**.

---

### 4️⃣ Write CLEAN, READABLE Code

```python
# Step 1: Import libraries
import numpy as np

# Step 2: Sample data
x = np.array([1, 2, 3, 4])
y = np.array([2, 4, 6, 8])
```

❌ No one-line magic
❌ No unexplained variables

---

### 5️⃣ Restart & Run All (Before Saving)

Before final save:

```
Runtime → Restart and run all
```

This ensures:

* No hidden state
* No broken cells
* Students won’t face errors

---

### 6️⃣ Save to **GitHub Organization Repo**

Now:

```
File → Save a copy in GitHub
```

Repository:

```
ORG_NAME/REPO_NAME
```

Folder:

```
03_Machine_Learning/01_Regression/
```

✔ This is now the **source of truth**

## 🔐 Version Control Rules (IMPORTANT)

* ❌ Don’t edit notebooks directly on GitHub UI
* ❌ Don’t keep multiple “final_v2” copies
* ✅ Use Git commit history
* ✅ One notebook = one concept

---

## 🚫 Common Mistakes (Avoid These)

❌ Creating `.ipynb` manually in GitHub
❌ Leaving outputs not executed
❌ No markdown explanation
❌ Random naming
❌ Mixing 3 concepts in one notebook
